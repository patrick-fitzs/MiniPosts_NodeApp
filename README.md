# MiniPosts Node App

A simple Node.js and Express application connected to MongoDB using Mongoose.  
This project demonstrates how to structure a basic REST API with environment variables and modular routing.

---

## 🧰 Tech Stack
- **Node.js**
- **Express.js**
- **MongoDB** (via Mongoose)
- **dotenv** for environment variables
- **Nodemon** for auto-restart during development

---

## ⚙️ Installation & Setup

1. **Clone this repo**
   ```bash
   git clone https://github.com/patrick-fitzs/MiniPosts_NodeApp.git
   cd MiniPosts_NodeApp

2. **Install Dependencies**
   npm install

3. **Add your .env files**
   DB_PASS=yourMongoDBPassword

4. **Run the Server**
   npm start
